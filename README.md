# SaaS源码集市

低价出售 SaaS 启动模板、UI 组件及独立开发资源的静态展示站点，托管于 GitHub Pages。

**在线访问：** [https://saas-sources.github.io/](https://saas-sources.github.io/)

## 内容分类

| 分类 | 说明 |
|------|------|
| SaaS 模板 | Supastarter、MkSaaS、ShipAny、TinyShip、MvpFast 等全栈启动器 |
| UI 模板 | Shadcn Studio、MagicUI、Aceternity UI、Tanstarter 等组件与页面模板 |
| 独立开发 | 定制开发服务、教程资料、部署指南等 |

## 项目结构

```
├── index.html      # 主页面
├── robots.txt      # 搜索引擎爬虫规则
├── sitemap.xml     # 站点地图
└── 66666666666666.png  # 微信联系二维码
```

## 本地预览

直接用浏览器打开 `index.html`，或使用任意静态服务器：

```bash
npx serve .
```

## 部署

推送到 `main` 分支后，在仓库 Settings → Pages 中启用 GitHub Pages 即可自动发布。
